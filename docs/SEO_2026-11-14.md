## Maintenance

`index.html` reste la source française commune. Modifier les textes dans ce fichier et les nouvelles traductions dans `assets/i18n/catalogue.json`, puis exécuter :

```powershell
python tools/build_i18n.py
python tools/build_seo.py
python tools/build_i18n.py --check
python tools/build_seo.py --check
python tools/test_seo.py
node tools/test_site.cjs
node tools/test_i18n.cjs
node tools/test_seo_browser.cjs
```

Les trois dernières commandes utilisent Playwright/Edge de développement. Aucun module npm n’est publié avec le site. Les générés HTML, sitemap et ZIP sont versionnés : GitHub Pages peut servir directement sans build. Vérifier la date de modification réelle dans le générateur lors d’une future modification. Les notes et actualités reprennent leur date d’annonce d’origine dans Article.

Contrôles réussis : 19 scénarios historiques, 9 scénarios de langues, 4 groupes de contrôles SEO parcourant les 48 pages ; Edge parcourt aussi les 48 pages avec et sans JavaScript, les drapeaux, la voix Yuki depuis une URL imbriquée, le lecteur YouTube et les vidéos. Captures mobile/bureau hors dépôt. Les services externes sont bloqués pendant les tests : ils ne valident ni référencement réel, ni installation Store, ni disponibilité des plateformes.

## Nuances et sources primaires

Les paramètres de langue ne sont pas intrinsèquement non indexables : des URL distinctes peuvent suffire. Les sous-répertoires retenus rendent ici les versions HTML explicites. Les fragments ne constituent pas des pages autonomes. VideoGame est descriptif mais ne garantit aucun résultat enrichi ; aucune note fictive ajoutée pour satisfaire un validateur. Un domaine propre apporte contrôle et cohérence de marque, sans garantir un meilleur classement.
