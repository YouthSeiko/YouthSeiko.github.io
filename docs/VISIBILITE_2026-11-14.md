# Publication et visibilité — 14 novembre 2026

YU autorise la publication du SEO, de la fiche des EX, des trois trailers et de l’encart Yuki, et les actions possibles pour la visibilité. Sources HEART et autres worktrees conservés.

Actions techniques préparées : fichier Google fourni par Search Console (propriété préfixe https://youthseiko.github.io/), vérification de propriété IndexNow à la racine, configuration indexnow.json et outil tools/notify_indexnow.py. Workflow IndexNow après Pages ou déclenchement manuel, action officielle checkout épinglée à v7.0.1, pas de clé GitHub persistée. Soumission des seules URL HTTPS canoniques du sitemap, même hôte, aucune URL privée ni paramètre.

Une réponse IndexNow 200 signifie réception ; 202 signifie réception et validation de clé en attente. Aucune de ces réponses ne prouve une indexation ou une position dans les résultats. Google reçoit le sitemap via Search Console ; ses anciens points de ping ne sont pas utilisés.

À contrôler après déploiement : pages publiques FR/EN/JA, médias, sitemap et fichiers de preuve ; validation Google puis soumission du sitemap ; conclusion du workflow IndexNow. La description et les sujets GitHub peuvent renvoyer vers le site public. Les résultats effectifs sont consignés dans la fiche SITE de la mémoire commune et le compte rendu final.
