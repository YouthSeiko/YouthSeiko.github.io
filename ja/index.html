💉 PROJECT MIRAI

最初の注射。

  • 縦スクロールシューティング
  • アーケード
  • 縦画面のモバイルゲーム
  • アニメ

小さな世界。戦う理由は、どこまでも大きい。

ミライの身体の中で、アカリは未来的な装備をまとい、架空の有機的な脅威に立ち向かいます。生きているような、不穏な景色をガーディアンの光が貫く、アニメ調の世界です。

すぐに飛び込めるバトル

指の移動量に応じたタッチ操作、自動射撃、そして回避。弾の動きを見逃さず、ボムや Neuro Burst で形勢を逆転。最後には2段階のボス戦が待っています。

リズム、手応え、個性

有機的な爆発、動くスコア、ダイナミックなフォンク、アカリの日本語ボイスとフランス語字幕が、プレイを彩ります。

開発はどこまで進んでいる？

現在のプロトタイプは、アカリと短いアーケードバトルが中心です。Android版をテスト中で、iPhone版も目標のひとつ。発売日や公開体験版は、まだ発表していません。

次の一歩は、スマホでの操作感を磨くこと。

青空高校へようこそ！ 主人公は、ごく普通の高校生・マサル。穏やかな一年を過ごすつもりだったのですが……。

気の強いゴス系の女の子、何でも勝負にしてしまうスポーツ少女、頭脳明晰だけど予測不能な少女、そして文学好きの内気な少女。4人との出会いで、日常は予想以上ににぎやかになりそう！

思いがけない出会い、不器用なデート、文化祭、ばかばかしい言い合い。そして、もしかすると恋の告白も。

🧊 PROJECT BABYLONE

どこかに、出口はある。

  • アクションRPG
  • メトロイドヴァニア
  • 探索
  • ミステリー

巨大な複合施設。無数の立方体。願うのはただひとつ、出口を見つけること。

知らない場所で目を覚ます。白い壁、幾何学的な部屋、どこまでも続く立方体の構造物。窓も、景色も、ここがどこなのかを示す手がかりもない。

ひとつだけ確かなことがある。出口は、きっとどこかにある。

🧩 巨大なパズルのような世界

無数の部屋がつながる、不思議な複合施設を探索しましょう。通路の先には、新たな場所や思わぬ障害、秘密があるかもしれません。場所を覚え、道を見つけ、この奇妙な空間の仕組みを少しずつ理解していきます。

🔓 探索して、進んで、戻って

メトロイドヴァニアのように、進むことで、それまで届かなかった場所へ行けるようになります。知っているはずの場所にも、新たな可能性が。探索、好奇心、観察力が、あなたの力になります。

🌐 外の世界の謎

この施設は、なぜ存在するのか。どれほど大きいのか。そして何より…… この壁の向こうには、どんな世界があるのか？

Project BABYLONE は、発見と謎を中心に据えた探索アドベンチャーです。

すべての部屋が問い。出口こそが答え。

🌼 PROJECT CENTURY

私のこと、大切にしてくれるよね？

  • ビジュアルノベル
  • シミュレーション
  • マネジメント
  • 心理ドラマ

親友はあなたを頼りにしている。少し、頼りすぎるほどに。

日々の暮らしは、簡単なことばかりではありません。買い物、支払い、思いがけない出来事、ちょっとした気づかい。時間とお金をやりくりする毎日で、親友もあなたを頼りにしているとしたら、ひとつひとつの決断は少し複雑になります。

🏡 日々の暮らしを整える

Project CENTURYでは、あなたにとって大切な人と日々を過ごします。相手を気づかい、予定を組み、それぞれの責任のバランスを取る。すぐに応えられる頼みごともあれば、何かを譲る必要があるものも。

💰 ひとつひとつの出費が大切

予算には限りがあります。お金を管理し、優先順位を決めて、日々の必要なものを選びましょう。小さな買い物が今日を楽しくしても……明日はどうなるのでしょう？

💬 変わっていく関係

会話や出来事を通して見えてくるのは、愛着、習慣、そして緊張が入り混じる複雑な友情。誰かを支えるのは素敵なこと。でも、自分の責任がどこまでなのか、見極めるのは簡単ではありません。

🌱 自分なりのバランスを探す

Project CENTURY は、物語とマネジメントを通して、人とのつながり、心の依存、自分自身の境界を描きます。

誰かを大切にすることは大事。自分を大切にすることも。

あなたは、自分のどこまでを差し出せますか？
